A reproducible prediction path

02 / METHOD
01

Protein-only input

A protein chain with matching sequence and Cα coordinates. Nucleic-acid coordinates and query binding labels are not inputs.

02

Frozen SSCP ensemble

SaProt and structure-aware ESM3 representations feed model C. The five fold probabilities—not logits—are averaged.

03

Remote interface memory

Qualified structural alignments project training-memory interface evidence. Uncovered residues retain the base prediction within the frozen clipping convention.

04

Task-specific fusion

DNA uses the frozen count-based rule. RNA uses CR: effective template count is one when a residue is covered.

BEFORE YOU SUBMIT

Know what the scores mean.

RIMBind estimates which protein residues may participate in DNA or RNA binding. A probability-colored surface is a prediction, not an experimentally established interface.

Read deployment and reproducibility notes ↗
Is online prediction already running?

No. The current page provides an example explorer, local input inspection and visualization of existing prediction CSV files. Live inference stays disabled until the external GPU pipeline, assets and numerical acceptance checks pass.

Can I submit only a sequence?

Not in the initial service. It requires a protein structure. This release does not offer automatic ColabFold/AlphaFold structure generation.

What stays private?

Local input inspection and CSV visualization run in your browser. No analytics or upload backend is configured on this page. External live inference, once enabled, will have its own explicit privacy and retention policy. Do not put private datasets or credentials in the public GitHub repository.

Why no performance number for my query?

AP, AUROC, F1 and MCC compare predictions with known experimental labels. A new unlabeled query has no such reference. A high prediction score alone is not a measured accuracy.

How should I cite this website?

The manuscript citation and permanent model-asset release are pending. This pre-release interface is not evidence that a public prediction server has been validated.
